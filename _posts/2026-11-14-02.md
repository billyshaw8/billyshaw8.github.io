整理了一份从零自学 AI 的路线，全部用斯坦福、伯克利、MIT 等名校的免费公开课，YouTube 上都能看。

分 6 个阶段，大约一年：
① 数学和 Python 基础
② 机器学习：CS229
③ 深度学习与视觉：Karpathy Zero to Hero → CS231n
④ NLP 与 Transformer：CS224N → CS336（从零训练一个语言模型）
⑤ 强化学习：CS234 + 伯克利 CS285
⑥ Agent：斯坦福今年秋天新开的 CS329Z + 伯克利 Agent 系列公开课

最重要的建议：一定要做作业，光看视频等于没学。

阶段 0：编程与数学基础

Python
- [ ] ⭐ Stanford Code in Place（CS106A 的免费线上版）— 官网 (codeinplace.stanford.edu)
- [ ] ○ Harvard CS50P：讲得非常好的 Python 入门  YouTube (youtube.com/playlist?list=…)

线性代数

- [ ] ⭐ MIT 18.06（Gilbert Strang）：经典中的经典 — · YouTube (youtube.com/playlist?list=…)
- [ ] ○ Stanford ENGR108（Boyd，就是上一版提到的 EE103，现在改了编号），更偏应用 — · YouTube (youtube.com/playlist?list=…)

概率与微积分
- [ ] ⭐ Stanford CS109 —  · YouTube 2022 (youtube.com/playlist?list=…)
- [ ] ○ Harvard Stat 110（Joe Blitzstein）：公认最好的概率课之一 — · YouTube (youtube.com/playlist?list=…)

阶段 1：机器学习

- [ ] ○ Coursera Machine Learning Specialization（吴恩达）：适合零基础，先建立直觉 — 官网 (coursera.org/specialization…)
- [ ] ⭐ Stanford CS229 —  · YouTube 2018 吴恩达版 (youtube.com/playlist?list=…)
- [ ] ○ Cornell CS4780（Kilian Weinberger）：直觉讲得最清楚的机器学习课之一，和 CS229 互补 — · YouTube (youtube.com/playlist?list=…)
- 验收项目：用 NumPy 从零实现线性回归、逻辑回归和 k-means，再用一个 Kaggle 数据集完整走一遍流程

阶段 2：深度学习 + 计算机视觉

- [ ] ○ 3Blue1Brown 神经网络系列：用动画讲清反向传播和 Transformer — YouTube (youtube.com/playlist?list=…)
- [ ] ⭐ Karpathy《Neural Networks: Zero to Hero》：从手写自动求导一路写到 GPT。这是理解深度学习最好的入门方式，后几集正好衔接阶段 3 —  ·YouTube (youtube.com/playlist?list=…)
- [ ] ⭐ Stanford CS231n —  · YouTube 2025 (youtube.com/playlist?list=…)（2026 年春季的录像只对选课学生开放）
- [ ] ○ UMich EECS 498/598（Justin Johnson）：相当于 CS231n 的加长版，作业质量很高，可以替代 CS231n —  · YouTube (youtube.com/playlist?list=…)
- [ ] ○ fast.ai Practical Deep Learning：先跑通，再深入原理 —  · YouTube (youtube.com/playlist?list=…)
- [ ] ○ MIT 6.S191：轻量入门课，每年更新 —  · YouTube (youtube.com/playlist?list=…)
- [ ] ○ Stanford CS230 —  · YouTube Autumn 2025 (youtube.com/playlist?list=…)
- [ ] ○ 生成模型：Stanford CS236 —  · YouTube 2023 (youtube.com/playlist?list=…)；MIT 6.S184 讲流匹配和扩散模型 —  · YouTube 2026 (youtube.com/playlist?list=…)
- 验收项目：完成 CS231n（或 EECS 498）的作业，再微调一个 ViT 或检测模型

阶段 3：NLP 与 Transformer

- [ ] ⭐ Stanford CS224N — · YouTube Spring 2024 (youtube.com/playlist?list=…)
- [ ] ○ Stanford CME 295：Transformer 和 LLM 概览 —· YouTube Autumn 2025 (youtube.com/playlist?list=…)
- [ ] ⭐ Stanford CS336 —  · YouTube Spring 2026 (youtube.com/playlist?list=…)
- [ ] ○ Stanford CS25：用来跟进前沿 — · YouTube (youtube.com/playlist?list=…)
- [ ] ○ CMU 11-711 Advanced NLP（Graham Neubig）：覆盖面很广，包括 RAG 和 Agent — · YouTube (youtube.com/playlist?list=…)
- [ ] ○ Hugging Face LLM Course：工程实战 — 官网 (huggingface.co/learn/llm-cour…)
- 验收项目：完成 CS336 作业 1，从零写一个 BPE tokenizer 和 Transformer 语言模型，并把它训练起来

阶段 4：强化学习

- [ ] ○ Sutton & Barto《Reinforcement Learning》教材 — 免费在线版 (incompleteideas.net/book/the-book-…)
- [ ] ○ David Silver RL 课（UCL × DeepMind 2015）：经典的理论入门 —  · YouTube (youtube.com/playlist?list=…)
- [ ] ⭐ Stanford CS234：打 RL 基础 — · YouTube Spring 2024 (youtube.com/playlist?list=…)
- [ ] ⭐ Berkeley CS285（Sergey Levine）：深度强化学习最权威的课 —  · YouTube 2023 (youtube.com/playlist?list=…)
- [ ] ○ Stanford CS224R：和 CS285 内容重叠，但用 RL 训练 LLM 的部分讲得更多 —  · YouTube (youtube.com/playlist?list=…)
- [ ] ○ OpenAI Spinning Up：给算法实现配上代码 — 官网 (spinningup.openai.com)
- [ ] ○ Hugging Face Deep RL Course — 官网 (huggingface.co/learn/deep-rl-…)
- [ ] ○ Stanford CS329H：RLHF 和偏好学习，Autumn 2026 正在开课 — 官网 (web.stanford.edu/class/cs329h/)
- [ ] ○ Stanford CS221：MDP 和博弈部分可以用来打基础 — · YouTube Autumn 2025 (youtube.com/playlist?list=…)
- 验收项目：在 Gymnasium 上实现 DQN 和 PPO。想进一步的话，用 GRPO 给一个小模型做推理能力的 RL 微调

阶段 5：Agent

- [ ] ⭐ Stanford CS329Z Engineering AI Agents —  · YouTube 第 1 讲 (youtube.com/watch?v=DGI4vu…)（目前已公开 1–4 讲，后续讲座在官网陆续发布）

  - LLM Agents（2024 秋）— · YouTube (youtube.com/playlist?list=…)
  - Advanced LLM Agents（2025 春）—  · YouTube (youtube.com/playlist?list=…)

- [ ] ○ Stanford CS222 AI Agents and Simulations：只有阅读材料，没有公开录像 — 官网 (joonspk-research.github.io/cs222-fall24/)
- [ ] ○ Hugging Face Agents Course：动手做 — 官网 (huggingface.co/learn/agents-c…)
- 验收项目：完成 CS329Z 的 HW1（不用框架写一个 agent）和 HW2（评测一个 agent）
